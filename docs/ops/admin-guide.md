# 관리자 사용 설명서

이 글은 쪽집게천사 대표님과 매장 직원이 관리자 화면을 쓸 때 보는 초안입니다.
오픈 전에 운영을 넘길 때 사용합니다.
2026-11-27에 관리자 화면에 있는 메뉴와 버튼을 보고 적었습니다.
화면에 없는 기능은 적지 않았습니다.
아직 화면만으로 단정하기 어려운 곳은 [확인 필요]로 표시했습니다.

위쪽 메뉴가 한 화면에 다 안 보이면 가로로 밀어 나머지 메뉴를 봅니다.
메뉴 순서는 아래와 같습니다.

1. 대시보드
2. 예약 관리
3. 주문 관리
4. 후기
5. 고객센터
6. 공지사항
7. 클래스
8. 선생님
9. 강의 비공개
10. 콘텐츠
11. 타로샵 상품
12. 상담사상품
13. 매장

날짜와 시각은 한국 시간입니다.
화면에도 "모든 날짜와 시각은 한국 시간(Asia/Seoul) 기준입니다."라고 나옵니다.

## 1. 처음 시작

### 로그인 주소

관리자 주소는 https://angelsaju.com/admin/login 입니다.
주소 끝은 `/admin/login`입니다.
들어가면 제목이 "쪽집게천사 운세통 관리자"입니다.

### 로그인 방법

이메일칸에 관리자 이메일을 입력합니다.
비밀번호칸에 비밀번호를 입력합니다.
로그인 버튼을 누릅니다.
누르는 동안 버튼 글자는 "로그인 중..."으로 바뀝니다.
맞으면 대시보드로 들어갑니다.
이메일이나 비밀번호가 다르면 "이메일 또는 비밀번호가 맞지 않아요."가 나옵니다.
관리자가 아닌 계정이면 "관리자 계정이 아니에요."가 나옵니다.
로그인된 상태가 관리자가 아니면 "관리자 권한이 없어요."가 나옵니다.
그때는 로그아웃을 누릅니다.

### 로그아웃

화면 오른쪽 위에 로그인한 이메일이 보입니다.
그 옆의 로그아웃을 누릅니다.
누르면 다시 로그인 화면으로 갑니다.
사이트 보기를 누르면 손님용 첫 화면으로 갑니다.
관리자에서 로그아웃되지는 않습니다.

### 비밀번호를 잊었을 때

로그인 화면 아래에 "비밀번호를 잊으셨으면 엠지미디어에 문의해 주세요."라고 적혀 있습니다.
관리자 화면에는 비밀번호를 바꾸는 메뉴가 없습니다.

### 관리자 계정을 새로 만들 때

관리자 계정을 만드는 메뉴는 없습니다.
[개발 담당에게 요청]합니다.

## 2. 메뉴별 사용법

각 메뉴는 언제 쓰나, 순서, 주의할 점으로 적습니다.

### 대시보드

메뉴 이름은 대시보드입니다.
들어가면 제목도 대시보드입니다.

**언제 쓰나**

오늘 상담 건수, 입금 대기 건수, 답하지 않은 문의를 한눈에 볼 때 씁니다.

**순서**

1. 로그인하면 이 화면이 먼저 나옵니다.
2. 오늘 예약의 건수를 봅니다.
3. 오늘 예약을 목록으로 보려면 오늘 예약 보기를 누릅니다.
4. 입금 대기의 건수를 봅니다.
5. 입금 대기만 보려면 입금 대기 보기를 누릅니다.
6. 다가오는 상담 일정에서 가까운 확정 예약 5건을 봅니다.
7. 최근 예약에서 방금 들어온 예약 5건을 봅니다.
8. 각 예약의 예약 상세를 누르면 그 예약으로 갑니다.
9. 미답변 문의 건수를 봅니다.
10. 미답변 문의 보기를 누르면 답변 대기인 문의만 나옵니다.

**주의할 점**

오늘 예약 건수는 취소된 예약을 빼고 셉니다.
오늘 예약 보기도 취소된 예약을 빼고 보여 줍니다.
입금 대기 건수는 날짜와 관계없이 입금 대기인 예약을 모두 셉니다.
다가오는 상담 일정은 확정이고 시작 시각이 아직 안 된 예약만 보여 줍니다.
미답변 문의 수를 불러오지 못하면 "미답변 문의 수를 불러오지 못했습니다. 다시 불러와 주세요."가 나옵니다.
그때는 화면을 다시 엽니다.

### 예약 관리

메뉴 이름은 예약 관리입니다.
목록 제목도 예약 관리입니다.
한 건을 열면 제목이 예약 상세입니다.

**언제 쓰나**

전화상담 예약의 입금을 확인하고, 상담이 끝나면 완료로 넘기고, 필요할 때 취소할 때 씁니다.

**순서**

1. 예약 관리를 누릅니다.
2. 상태에서 전체를 두거나 입금 대기, 확정, 완료, 취소 중 하나를 고릅니다.
3. 상담사에서 전체 상담사 또는 한 명을 고릅니다.
4. 상담 시작일 (부터)와 상담 시작일 (까지)를 고릅니다.
5. 정렬에서 예약 최신순, 상담일 늦은순, 날짜순 중 하나를 고릅니다.
6. 취소된 예약을 빼려면 취소 예약 제외를 켭니다.
7. 필터 적용을 누릅니다.
8. 조건을 지우려면 초기화를 누릅니다.
9. 목록에서 예약 상세를 누릅니다.
10. 예약 목록으로를 누르면 목록으로 돌아갑니다.
11. 무통장입금이고 상태가 입금 대기이면 입금 확인 후 예약 확정을 누릅니다.
12. 창의 안내를 읽습니다.
13. 확인 후 처리를 누릅니다.
14. 돌아가기를 누르면 처리하지 않고 창이 닫힙니다.
15. 상태가 확정이고 상담 종료 시각이 지난 뒤 상담 완료 처리를 누릅니다.
16. 확인 후 처리를 누릅니다.
17. 취소할 때는 예약 취소를 누릅니다.
18. 취소 사유 (필수, 1~500자)를 적습니다.
19. 확인 후 처리를 누릅니다.

**주의할 점**

입금 확인 후 예약 확정은 결제 방식이 무통장입금이고 상태가 입금 대기일 때만 보입니다.
창에는 "실제 입금 내역을 확인한 뒤 확정해 주세요. 상담 시작 전 예약만 확정할 수 있습니다."라고 나옵니다.
통장에서 입금을 본 뒤에만 확정합니다.
상담 시작 시각이 지난 예약은 확정할 수 없습니다.
확정에 성공하고 메일이 나가면 "예약 상태를 변경했습니다. 확정 메일을 보냈습니다."가 나옵니다.
예약은 확정됐지만 메일이 실패하면 "예약 상태를 변경했습니다. 확정 메일은 보내지 못했습니다."가 나옵니다.
손님에게 가는 메일 제목은 "[쪽집게천사 운세통] 예약이 확정되었습니다"입니다.
확정 메일을 보냈습니다라는 문장이 보여야 메일이 나간 것으로 봅니다.
메일을 다시 보내는 버튼은 없습니다.
상담 완료 처리는 상태가 확정일 때만 보입니다.
창에는 "상담 종료 시각 이후에만 완료할 수 있습니다."라고 나옵니다.
완료된 뒤에 손님이 후기를 쓸 수 있습니다.
완료·취소된 예약은 변경할 수 없습니다.
화면에 "완료·취소된 예약은 변경할 수 없습니다."라고 나옵니다.
예약 취소는 입금 대기이거나 확정일 때만 됩니다.
취소 사유는 손님이 볼 수 있습니다.
창에는 "고객이 볼 수 있으므로 개인정보나 내부 평가를 적지 마세요."라고 나옵니다.
취소는 예약 상태만 바꿉니다.
환불이 필요하면 따로 처리합니다.
창에도 "예약 상태만 취소되며, 환불이 필요한 경우 별도로 처리해야 합니다."라고 나옵니다.
예약 입력 화면에는 "예약 후 24시간 안에 입금해 주세요. 입금 확인 후 확정돼요."라고 나옵니다.
예약이 접수된 화면에는 "예약 후 24시간 안에 입금해 주세요. 입금이 확인되면 예약이 확정돼요."라고 나옵니다.
입금 대기인 예약은 접수한 시각부터 24시간이 지나면 자동으로 취소됩니다.
자동 취소는 한 시간마다 한 번씩 확인합니다.
24시간이 지난 직후가 아니라 다음 정각 확인 때 취소될 수 있습니다.
손님이 그 시간을 다시 예약할 때도, 기한이 지난 입금 대기는 취소될 수 있습니다.
자동 취소된 예약의 상태 글자는 "입금 기한 경과로 취소"입니다.
상담 시작일이 많이 남아 있어도, 입금 확인을 24시간 안에 하지 않으면 취소됩니다.
손님 예약 완료 화면의 계좌 자리는 지금 "[입금 계좌 준비 중]"입니다.
[확인 필요] 실제 입금 계좌를 손님 화면에 언제 넣을지는 개발 담당에게 확인해 주세요.
손님 예약 화면의 금액 옆에는 "예시 가격"이 같이 보입니다.
[확인 필요] 오픈 때에도 이 글자를 둘지는 개발 담당에게 확인해 주세요.
다른 사람이 먼저 바꾼 예약이면 "다른 작업으로 예약이 변경됐습니다. 새로고침 후 다시 확인해 주세요."가 나옵니다.
그때는 화면을 새로 고친 뒤 상태를 다시 봅니다.
한 페이지에 20건씩 나옵니다.
이전과 다음으로 페이지를 바꿉니다.

### 주문 관리

메뉴 이름은 주문 관리입니다.
목록 제목도 주문 관리입니다.
한 건을 열면 제목이 주문 상세입니다.
타로샵에서 손님이 주문한 실물 상품을 처리합니다.

**언제 쓰나**

타로샵 주문의 입금을 확인하고, 택배를 보내고, 배송이 끝나면 완료할 때 씁니다.

**순서**

1. 주문 관리를 누릅니다.
2. 상태에서 전체, 입금 대기, 입금 확인, 배송 중, 완료, 취소 중 하나를 고릅니다.
3. 필터 적용을 누릅니다.
4. 조건을 지우려면 필터 초기화를 누릅니다.
5. 목록에서 주문 상세를 누릅니다.
6. 주문 목록으로를 누르면 목록으로 돌아갑니다.
7. 상태가 입금 대기이면 입금 확인을 누릅니다.
8. 창에는 "실제 입금 내역을 확인한 뒤 처리해 주세요."라고 나옵니다.
9. 확인 후 처리를 누릅니다.
10. 상태가 입금 확인이 되면 배송 중으로 변경을 누릅니다.
11. 송장번호 (필수, 1~100자)를 입력합니다.
12. 확인 후 처리를 누릅니다.
13. 상태가 배송 중이면 주문 완료를 누릅니다.
14. 창에는 "배송 완료를 확인한 뒤 주문을 완료해 주세요."라고 나옵니다.
15. 확인 후 처리를 누릅니다.
16. 진행 중인 주문을 취소하려면 주문 취소를 누릅니다.
17. 확인 후 처리를 누릅니다.

**주의할 점**

버튼 이름 입금 확인과 상태 이름 입금 확인은 같은 글자입니다.
입금 대기일 때 그 버튼을 누르면 상태가 입금 확인으로 바뀝니다.
배송 중으로 바꾸려면 먼저 입금 확인 상태여야 합니다.
송장번호가 없으면 배송 중으로 바뀌지 않습니다.
창에는 "저장한 송장번호는 고객 주문 조회에 바로 표시됩니다."라고 나옵니다.
주문 완료는 배송 중일 때만 됩니다.
완료·취소된 주문은 변경할 수 없습니다.
화면에 "완료·취소된 주문은 변경할 수 없습니다."라고 나옵니다.
주문 취소는 입금 대기, 입금 확인, 배송 중일 때 됩니다.
주문 취소에는 사유 칸이 없습니다.
창에는 "환불이 필요한 경우 별도로 처리해야 합니다."라고 나옵니다.
주문 취소는 환불까지 해 주지 않습니다.
처리가 되면 "주문 상태를 변경했습니다."가 나옵니다.
다른 사람이 먼저 바꾸면 "다른 작업으로 주문이 변경됐습니다. 새로고침 후 다시 확인해 주세요."가 나옵니다.
목록은 주문 접수 최신순입니다.
한 페이지에 20건씩 나옵니다.
이 화면은 전화상담 예약과 따로입니다.
상담 예약의 입금은 예약 관리에서 처리합니다.

### 후기

메뉴 이름은 후기입니다.
들어가면 제목이 후기 관리입니다.

**언제 쓰나**

손님이 쓴 후기를 손님 화면에서 숨기거나, 숨긴 후기를 다시 공개할 때 씁니다.

**순서**

1. 후기를 누릅니다.
2. 공개 상태에서 전체, 공개, 숨김 중 하나를 고릅니다.
3. 필터 적용을 누릅니다.
4. 조건을 지우려면 초기화를 누릅니다.
5. 공개 중인 후기에서 숨김으로 전환을 누릅니다.
6. "후기를 숨겼습니다."가 나오면 숨긴 것입니다.
7. 숨긴 후기를 다시 보이려면 공개로 전환을 누릅니다.
8. "후기를 공개했습니다."가 나오면 다시 공개된 것입니다.

**주의할 점**

화면에는 "후기 내용은 바꾸지 않고 공개 여부만 관리합니다."라고 나옵니다.
후기 글을 고치거나 지우는 버튼은 없습니다.
처리 중에는 버튼 글자가 "처리 중"으로 바뀝니다.
조건에 맞는 후기가 없으면 "조건에 맞는 후기가 없습니다."가 나옵니다.
여러 페이지면 이전과 다음이 나옵니다.

### 고객센터

메뉴 이름은 고객센터입니다.
누르면 문의 관리로 들어갑니다.
그 안의 메뉴는 문의 관리와 FAQ 관리입니다.

**언제 쓰나**

손님이 남긴 1:1 문의에 답할 때 씁니다.
손님 화면에 보이는 자주 묻는 질문을 등록하거나 고칠 때도 씁니다.

여기서 상담사와 전화상담 상품을 다룹니다.

**언제 쓰나**

상담사를 손님에게 보일지 정할 때 씁니다.
상담 상품의 이름, 시간, 가격을 바꾸거나 판매를 멈출 때도 씁니다.
사진을 바꿀 때도 씁니다.

**순서**

1. 상담사상품을 누릅니다.
2. 공개 상태에서 전체, 공개, 비공개를 고르고 필터 적용을 누릅니다.
3. 조건을 지우려면 초기화를 누릅니다.
4. 새 상담사는 상담사 등록을 누릅니다.
5. 이름, 전체 분야, 대표 분야, 소속 매장, 소개를 적습니다.
6. 상담 주제와 경력·교육·자격이 있으면 칸을 추가해 하나씩 적습니다.
7. 사진은 사진 선택을 눌러 고릅니다.
8. 추천으로 보이려면 추천 상담사를 켭니다.
9. 신규로 보이려면 신규 상담사를 켭니다.
10. 손님에게 보이려면 공개를 켭니다.
11. 저장 전 확인을 누릅니다.
12. 확인 창에서 내용을 확인합니다.
13. 확인 후 처리를 누릅니다.
14. 있는 상담사는 편집을 누릅니다.
15. 그 상담사의 상품은 상품 관리를 누릅니다.
16. 상담 상품 등록을 눌러 상품을 만듭니다.
17. 상품명, 상담 시간(분), 가격(원), 정렬 순서를 적습니다.
18. 팔려면 공개를 켭니다.
19. 저장 전 확인을 누른 뒤 확인 후 처리를 누릅니다.
20. 있는 상품은 편집을 눌러 가격 등을 고칩니다.

**주의할 점**

손님에게 숨기려면 공개를 끄고 저장합니다.
화면에는 "고객 화면에서 숨기려면 공개를 해제합니다. 상담사 삭제는 하지 않습니다."라고 나옵니다.
상담사를 지우는 버튼은 없습니다.
상담 상품도 지우는 버튼은 없습니다.
판매를 멈추려면 상품의 공개를 끄고 저장합니다.
화면에는 "판매를 중단하려면 비공개로 전환합니다. 상품은 삭제하지 않습니다."라고 나옵니다.
상품을 고쳐도 이미 잡힌 예약의 상품명, 시간, 금액은 바뀌지 않습니다.
화면에도 그 문장이 있습니다.
상품을 공개해도 상담사가 비공개이거나 승인이 아니면 손님 화면에 안 나옵니다.
목록에 승인 대기나 거절이 보이면 공개를 켜도 손님에게 안 보입니다.
승인 상태를 바꾸는 버튼은 없습니다.
바꿔야 하면 [개발 담당에게 요청]합니다.
새 상담사를 저장하면 승인 상태로 시작됩니다.
사진이 없으면 손님 화면에는 천사 로고가 나옵니다.
사진 파일은 JPEG, PNG, WebP만 됩니다.
빈 파일은 안 됩니다.
한 장은 5MiB까지입니다.
맞지 않으면 "사진은 5MiB 이하의 빈 파일이 아닌 파일을 선택해 주세요." 또는 "JPEG·PNG·WebP 사진의 실제 형식과 MIME이 일치해야 합니다."가 나옵니다.
고른 파일이 아직 저장 전이면 선택한 파일 취소를 누릅니다.
사진을 빼려면 사진 제거를 누릅니다.
크게 보려면 사진 크게 보기를 누릅니다.
화면에는 "비공개 상담사 사진도 주소를 알면 누구나 볼 수 있습니다. 공개할 수 있는 사진만 올려 주세요."라고 나옵니다.
사진 고르는 칸에는 권장 가로세로 크기가 적혀 있지 않습니다.
[확인 필요] 사진을 4:5로 준비해야 하는지는 개발 담당에게 확인해 주세요.
가격은 0원도 저장됩니다.
실제 판매 가격이 아니면 공개하지 않습니다.
상담 시간(분)은 30분 단위가 아니어도 저장됩니다.
정렬 순서가 작은 상품이 앞에 나옵니다.
저장하지 않고 나가려면 확인 창에서 목록으로 이동을 누릅니다.
다른 내용이 먼저 저장됐으면 최신 내용 다시 불러오기를 누릅니다.

### 매장

메뉴 이름은 매장입니다.
들어가면 제목이 매장 관리입니다.

**언제 쓰나**

매장 이름, 주소, 영업시간, 전화번호, 사진을 등록하거나 손님에게 보일지 정할 때 씁니다.

**순서**

1. 매장을 누릅니다.
2. 매장 등록을 누릅니다.
3. 매장명, 소개, 주소, 영업시간 안내, 전화번호를 적습니다.
4. 사진은 사진 선택을 눌러 고릅니다.
5. 정렬 순서를 적습니다.
6. 손님에게 보이려면 공개를 켭니다.
7. 저장 전 확인을 누릅니다.
8. 확인 후 처리를 누릅니다.
9. 있는 매장은 편집을 누릅니다.
10. 손님에게 숨기려면 공개를 끄고 저장합니다.
11. 매장을 지울 때는 먼저 비공개로 저장합니다.
12. 연결된 상담사가 없어야 합니다.
13. 매장 삭제를 누릅니다.
14. 매장 영구 삭제를 누릅니다.

**주의할 점**

공개 상태에서 전체, 공개, 비공개를 고르고 필터 적용을 누릅니다.
초기화를 누르면 조건이 지워집니다.
공개를 끄고 저장하면 손님 화면에서 숨겨집니다.
매장 자체는 그때 삭제되지 않습니다.
확인 창에는 "공개를 해제하면 고객 화면에서 숨겨집니다. 매장은 삭제하지 않습니다."라고 나옵니다.
공개인 매장은 바로 지우지 못합니다.
먼저 비공개로 저장해야 합니다.
화면에는 "매장을 삭제하려면 공개를 해제한 상태를 먼저 저장해야 합니다."라고 나옵니다.
공개 체크만 끄고 저장하지 않으면 삭제할 수 없습니다.
연결된 상담사가 있으면 "연결된 상담사가 있습니다. 상담사 관리에서 소속을 변경하거나 해제한 뒤 다시 시도해 주세요."가 나옵니다.
삭제한 매장은 복구할 수 없습니다.
창에는 "삭제한 매장은 복구할 수 없습니다."라고 나옵니다.
사진 안내에는 "JPEG, PNG, WebP 1장. 빈 파일은 올릴 수 없고 5MiB까지입니다."라고 나옵니다.
비공개 매장 사진도 주소를 알면 누구나 볼 수 있습니다.
공개할 수 있는 사진만 올립니다.
저장되면 "매장을 저장했습니다."가 나옵니다.
삭제되면 "매장을 삭제했습니다."가 나옵니다.

## 3. 자주 하는 일 바로가기

### 오늘 예약 확인하기

1. 대시보드를 엽니다.
2. 오늘 예약 건수를 봅니다.
3. 오늘 예약 보기를 누릅니다.
4. 예약 상세를 눌러 상담사, 손님, 시작 시각을 확인합니다.

오늘 예약 보기에는 취소된 예약이 빠집니다.
취소된 건까지 보려면 예약 관리에서 취소 예약 제외를 끄고 필터 적용을 누릅니다.

### 입금 확인하기

전화상담 입금은 예약 관리에서 합니다.

1. 대시보드에서 입금 대기 보기를 누릅니다.
2. 예약 상세를 누릅니다.
3. 결제 방식이 무통장입금인지 봅니다.
4. 입금자명을 봅니다.
5. 통장에서 그 금액이 들어왔는지 확인합니다.
6. 입금 확인 후 예약 확정을 누릅니다.
7. 확인 후 처리를 누릅니다.
8. "예약 상태를 변경했습니다. 확정 메일을 보냈습니다."를 확인합니다.

타로샵 주문 입금은 주문 관리에서 합니다.

1. 상태에서 입금 대기를 고르고 필터 적용을 누릅니다.
2. 주문 상세를 누릅니다.
3. 통장에서 총 금액을 확인합니다.
4. 입금 확인을 누릅니다.
5. 확인 후 처리를 누릅니다.

### 문의 답하기

1. 대시보드에서 미답변 문의 보기를 누릅니다.
2. 상세 보기를 누릅니다.
3. 문의 내용을 읽습니다.
4. 답변칸에 손님에게 보일 글만 적습니다.
5. 저장 전 확인을 누릅니다.
6. 확인 후 처리를 누릅니다.
7. "답변을 저장했습니다."를 확인합니다.
8. "답변을 저장했습니다. 알림 메일은 보내지 못했습니다."가 보이면 답변은 저장됐고 메일만 실패한 것입니다.

### 후기 숨기기

1. 후기를 누릅니다.
2. 공개 상태를 공개로 두고 필터 적용을 누릅니다.
3. 해당 후기에서 숨김으로 전환을 누릅니다.
4. "후기를 숨겼습니다."를 확인합니다.

### 상담 상품 가격 바꾸기

1. 상담사상품을 누릅니다.
2. 그 상담사의 상품 관리를 누릅니다.
3. 상품의 편집을 누릅니다.
4. 가격(원)을 바꿉니다.
5. 저장 전 확인을 누릅니다.
6. 확인 후 처리를 누릅니다.

이미 잡힌 예약의 금액은 바뀌지 않습니다.
앞으로 새로 예약하는 손님부터 새 가격이 적용됩니다.
판매를 멈추려면 가격을 0으로 만들지 않고 공개를 끄고 저장합니다.

## 4. 문제가 생겼을 때

### 손님이 메일을 못 받았다고 할 때

예약 확정 메일과 문의 답변 메일을 나눠 확인합니다.

예약 메일인지 확인합니다.

1. 예약 관리에서 그 예약의 예약 상세를 엽니다.
2. 상태가 확정인지 봅니다.
3. 고객 정보의 이메일이 손님이 말한 주소와 같은지 봅니다.
4. 확정할 때 화면에 "예약 상태를 변경했습니다. 확정 메일을 보냈습니다."가 나왔는지 기억합니다.
5. 손님에게 메일 제목 "[쪽집게천사 운세통] 예약이 확정되었습니다"를 찾아 보게 합니다.
6. 스팸함도 보게 합니다.

이 메일은 입금 확인 후 예약 확정을 성공시켰을 때만 갑니다.
상담 완료 처리나 예약 취소를 눌러도 확정 메일은 가지 않습니다.
"예약 상태를 변경했습니다. 확정 메일은 보내지 못했습니다."가 나왔으면 예약은 확정이고 메일만 실패한 것입니다.

문의 메일인지 확인합니다.

1. 고객센터의 문의 관리에서 그 문의를 엽니다.
2. 고객 정보의 이메일을 확인합니다.
3. 상태가 답변 완료인지 봅니다.
4. 손님에게 메일 제목 "[쪽집게천사 운세통] 문의하신 내용에 답변이 등록됐어요"를 찾아 보게 합니다.
5. 스팸함도 보게 합니다.

이 메일은 처음 답변을 저장할 때만 갑니다.
답변을 고쳐서 다시 저장해도 메일은 다시 가지 않습니다.
손님은 메일이 없어도 문의 조회에서 답변을 볼 수 있습니다.

메일을 다시 보내는 버튼은 없습니다.
개발 담당에게 알릴 때는 아래를 적습니다.

- 예약이면 예약번호, 문의이면 문의번호
- 화면에 나온 문장 전체
- 손님 이메일이 예약 또는 문의의 이메일과 같은지
- 손님이 스팸함도 확인했는지

### 예약 시간이 막혀 있을 때

손님이 고를 수 있는 조건은 아래와 같습니다.

상담을 고를 수 있는 날은 오늘부터 14일 뒤까지입니다.
시작 시각은 낮 12시부터 밤 10시 전입니다.
시작 시각은 30분 간격입니다.
상담이 밤 10시를 넘기면 그 시작 시각은 막힙니다.
지금으로부터 2시간 이내의 시각은 막힙니다.
확정된 예약이 그 시간과 겹치면 막힙니다.
접수한 지 24시간이 안 된 입금 대기 예약이 겹쳐도 막힙니다.
완료나 취소된 예약은 시간을 막지 않습니다.
입금 대기라도 접수한 지 24시간이 지나면 그 시간은 다시 열립니다.
상담사와 상담 상품이 공개이고, 상담사가 승인이어야 예약 화면이 나옵니다.

확인할 순서입니다.

1. 예약 관리에서 그 상담사를 고릅니다.
2. 막힌 날짜를 상담 시작일 (부터)와 상담 시작일 (까지)에 넣습니다.
3. 필터 적용을 누릅니다.
4. 겹치는 예약이 확정인지 입금 대기인지 봅니다.
5. 입금 대기이면 접수 시각이 24시간을 넘었는지 봅니다.
6. 상태가 "입금 기한 경과로 취소"이면 그 예약은 시간을 막지 않습니다.
7. 상담 상품의 상담 시간(분)이 밤 10시를 넘기는지 봅니다.
8. 상담사 관리에서 공개와 승인 상태를 봅니다.

그래도 빈 시간이 막혀 있으면 개발 담당에게 아래를 알립니다.

- 상담사 이름
- 상품명과 상담 시간(분)
- 막힌 날짜와 시각
- 그 시각과 겹쳐 보이는 예약번호와 상태
- 화면에 나온 문장

### 사진이 안 보일 때

사진이 없으면 아래처럼 보입니다.

상담사 사진이 없으면 천사 로고가 나옵니다.
타로샵 상품 사진이 없으면 "상품 사진 없음"이 나옵니다.
사진을 불러오지 못하면 "상품 사진을 불러오지 못했습니다."가 나옵니다.
매장 사진이 없으면 "사진 준비 중"이 나옵니다.

확인할 순서입니다.

1. 관리자에서 그 항목의 편집을 엽니다.
2. 미리보기에 사진이 있는지 봅니다.
3. 미리보기가 없으면 사진 선택으로 다시 고릅니다.
4. 파일이 JPEG, PNG, WebP인지 확인합니다.
5. 파일 크기가 5MiB를 넘는지 확인합니다.
6. 저장 전 확인을 누른 뒤 확인 후 처리까지 했는지 확인합니다.
7. 공개가 켜진 채로 저장됐는지 확인합니다.
8. 상담사면 승인 대기나 거절이 아닌지 확인합니다.
9. 상담 상품이면 상담사도 공개이고 승인인지 확인합니다.
10. 손님 화면을 새로 고칩니다.

업로드가 실패하면 화면에 나온 문장을 그대로 둡니다.
자주 나오는 문장은 아래입니다.

- 사진은 5MiB 이하의 빈 파일이 아닌 파일을 선택해 주세요.
- JPEG·PNG·WebP 사진의 실제 형식과 MIME이 일치해야 합니다.
- 사진을 업로드하지 못했습니다. 다시 시도해 주세요.
- 사진 업로드에 실패했습니다.

개발 담당에게 알릴 때는 아래를 적습니다.

- 대시보드가 아니라 어느 메뉴인지
- 상담사, 매장, 상품 중 무엇인지와 이름
- 관리자 미리보기에는 사진이 보이는지
- 화면에 나온 문장 전체

## 5. 하지 말아야 할 것

비밀번호를 직원끼리 공유하지 않습니다.
비밀번호를 메모장이나 단톡방에 적지 않습니다.
공용 컴퓨터를 쓰면 일을 끝낸 뒤 로그아웃을 누릅니다.
관리자 계정이 필요하면 비밀번호를 알려 주지 말고 [개발 담당에게 요청]합니다.

연습으로 만든 상담사, 상품, 공지, 클래스, 콘텐츠를 공개로 두지 않습니다.
클래스의 사주 과정 예시와 타로 과정 예시를 실제 수업 안내처럼 공개하지 않습니다.
가격이 0원인 상담 상품을 실제 상품처럼 공개하지 않습니다.
아직 확정되지 않은 가격을 손님에게 확정 가격처럼 말하지 않습니다.
손님 예약 화면에는 금액 옆에 "예시 가격"이 보입니다.

입금 계좌 화면이 "[입금 계좌 준비 중]"이면 다른 계좌번호를 그 자리에 있는 것처럼 안내하지 않습니다.
통장에서 입금을 확인하기 전에 입금 확인 후 예약 확정이나 입금 확인을 누르지 않습니다.

취소 사유와 문의 답변에는 손님에게 보이면 안 되는 말을 적지 않습니다.
내부 평가, 다른 손님 이야기, 직원만 아는 메모를 적지 않습니다.

공개하지 않을 사진을 올리지 않습니다.
비공개로 저장해도 사진 주소를 알면 볼 수 있습니다.

예약 취소나 주문 취소를 눌렀다고 환불까지 끝난 것으로 보지 않습니다.
환불은 따로 처리합니다.

완료나 취소로 끝난 예약과 주문을 화면에서 되돌리려 하지 않습니다.
그 버튼은 나오지 않습니다.
되돌려야 하면 [개발 담당에게 요청]합니다.
