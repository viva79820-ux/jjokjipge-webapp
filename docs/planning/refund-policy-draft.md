# 쪽집게천사 민원·환불 처리 방침 (초안 v0.1)

초안 v0.1 · 2026.11.03 · 작성: 엠지미디어 · 쪽집게천사 검토·수정용

> 엠지미디어가 작성해 대표님께 전달한 초안(원본은 Word 파일). 쪽집게천사가 **[결정 필요]** 부분을 고쳐 회신하면 확정한다.
> 이 문서는 법률 자문이 아니다. 법(전자상거래법)보다 고객에게 불리한 환불 규정은 효력이 없다.

## 1. 적용 범위

| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |

| 홈페이지 타로카드 판매(실물 상품)  | 이 방침 2장(민원)과 4장(환불)을 적용합니다.                                                                                                |
| 홈페이지 강의                      | 무료 열람이라 환불 대상이 없습니다(5장). 유료로 바꾸면 그때 따로 정합니다.                                                                 |
| 매장 방문 상담                     | 매장에서 결제한 상담의 환불은 매장 규정을 따릅니다 **\[결정 필요: 매장 규정이 따로 있는지\]**. 상담사 관련 민원은 2장을 똑같이 적용합니다. |
| 네이버 엑스퍼트 상담(제휴 승인 시) | 결제·환불은 네이버 엑스퍼트 운영정책을 따릅니다. 쪽집게천사 소속 상담사에 대한 민원 처리와 상담사 조치는 2장을 적용합니다.                 |

## 2. 민원 처리

### 2.1 접수 창구

- 홈페이지 1:1 문의: 24시간 접수, 영업일에 답변

- 매장 대표전화: 영업시간 중 접수 **\[결정 필요: 대표번호, 접수 가능
  시간\]

- 이메일: **\[결정 필요: 민원 접수용 이메일 주소\]

어느 창구로 들어온 민원이든 같은 기록 양식(2.4)에 남깁니다.

### 2.2 처리 기한

| **단계**       | **기한**                  | **비고**                                                                                         |
| -------------- | ------------------------- | ------------------------------------------------------------------------------------------------ |
| 접수 확인 안내 | **\[1영업일\]** 이내      | "접수되었습니다"와 담당자를 알립니다.                                                            |
| 처리 결과 안내 | **\[3영업일\]** 이내      | 상담사 진술 등 사실 확인이 필요하면 **\[7영업일\]**까지. 늦어지면 사유와 예정일을 먼저 알립니다. |
| 환불 금액 지급 | 환불 확정 후 3영업일 이내 | 법정 기한입니다(전자상거래법 제18조 제2항). 줄일 수는 있어도 늘릴 수는 없습니다.                 |

제안값은 상담사 약 10명 규모의 매장에서 대표님이나 매장 관리자가 직접
처리할 수 있는 수준으로 잡았습니다.

### 2.3 처리 담당

- 1차 담당(접수·사실 확인·고객 안내): **\[결정 필요: 매장 관리자
  이름\]

- 최종 결정(환불 승인, 상담사 조치): **\[결정 필요: 대표 이름\]

### 2.4 처리 절차와 기록

1.  접수: 고객 이름, 연락처, 예약번호(또는 주문번호), 민원 내용, 접수
    일시를 기록합니다.

2.  사실 확인: 예약 기록, 상담 시작·종료 시각, 통화 기록, 상담사 진술을
    확인합니다.

3.  결정: 2.5 기준표에 따라 처리 방법을 정합니다. 기준표에 없는 경우는
    최종 결정자가 정합니다.

4.  안내: 고객에게 결과와 이유를 알립니다. 환불이면 금액과 지급 예정일을
    함께 알립니다.

5.  보관: 처리 결과까지 기록해 보관합니다(2.7).

### 2.6 상담사 관리

온라인 상담에서 아래 행위는 금지합니다. 상담사에게 미리 알리고 동의를
받습니다 **\[결정 필요: 서면 동의 방식\]**.

- 불안이나 공포를 키우는 말("큰일 난다", "지금 안 하면 화를 입는다" 등)

- 부적, 굿, 추가 상담 등 추가 결제를 유도하는 행위

- 의료, 법률, 투자 결정을 단정하는 말(전문가 상담을 권해야 함)

- 고객과 개인 연락처를 주고받거나, 홈페이지 밖에서 따로 결제받는 행위

- 상담 내용을 외부에 알리는 행위

민원이 확인된 상담사에 대한 조치(제안):

| **단계**              | **조치**                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| 주의                  | 확인된 민원 1회. 내용을 알리고 기록합니다.                                                        |
| 경고                  | 같은 유형 **\[2회\]**, 또는 경고 대상 유형 1회. 서면으로 알립니다.                                |
| 온라인 상담 배정 중단 | 경고 후 다시 발생하거나 금지 행위·중대 위반 1회. 기간은 최종 결정자가 정합니다 **\[결정 필요\]**. |

상담사에게 책임이 있는 환불 금액을 정산에서 어떻게 처리할지는 쪽집게천사
내부 정산 방식에 따릅니다 **\[결정 필요\]**.

## 3. 환불 기준: 전화상담(예약형)

진행 방식: 고객이 상담사, 상담 상품, 날짜·시간을 골라 예약하고 결제하면,
예약한 시간에 상담사가 매장 전화로 고객에게 전화합니다.

| **상황**                                         | **환불**                                                                           | **이유**                                                                                                                                           |
| ------------------------------------------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상담 시작 전 고객이 취소                         | **전액 환불**, 수수료·위약금 없음                                                  | 상담 제공이 시작되기 전에는 청약철회가 가능하고, 철회를 이유로 위약금을 받을 수 없습니다(전자상거래법 제17조 제1항, 제18조 제9항).                 |
| 상담이 시작된 뒤                                 | 환불하지 않음(아래 상담사 쪽 사유 제외)                                            | 용역 제공이 시작되면 청약철회가 제한됩니다(제17조 제2항 제5호). 단, 결제 전에 이 사실을 고객이 알 수 있게 표시해야 합니다(제17조 제6항, 6장 문구). |
| 상담사 쪽 사유(불참, 지각, 시간 미달, 통화 끊김) | 전액 환불 또는 재예약 중 고객 선택, 시간 미달은 2.5 기준                           | 고객 책임이 없기 때문입니다.                                                                                                                       |
| 고객 부재(전화를 받지 않음)                      | **\[1회 무료 재예약\]**. 재예약에도 부재면 상담을 제공한 것으로 보고 환불하지 않음 | 상담사는 그 시간을 비워 두었기 때문입니다. 아래 부재 처리 절차를 지킨 경우에만 적용합니다.                                                         |

**고객 부재 처리 절차(제안)**: 예약 시간에 상담사가 **\[3회\]
전화하고, 받지 않으면 문자로 안내한 뒤 **\[10분\]** 기다립니다. 그래도
연락이 없으면 부재로 기록하고 재예약을 안내합니다. 부재 처리 기준은 법에
따로 정한 것이 없어 분쟁이 생길 수 있으므로, 시행 전에 확인을 권합니다.

**취소 방법**: 상담 시작 전까지 매장 대표전화 또는 홈페이지 1:1 문의로
취소합니다. 상담사 일정 조정을 위해 가능하면 **\[1시간\]** 전까지 연락을
부탁드린다고 안내합니다(늦게 취소해도 시작 전이면 전액 환불).

**무통장입금 예약의 입금 기한**: 예약 후 **\[24시간\]** 안에 입금되지
않으면 예약을 자동 취소하고 그 시간을 다시 엽니다. 다른 고객이 그 시간을
예약할 수 있게 하기 위해서입니다.

**참고**: 다른 업체에서 흔히 보이는 "당일 취소 50% 공제" 같은 규정은
온라인 판매에서는 위 법 조항과 충돌할 수 있어 초안에 넣지 않았습니다. 꼭
필요하시면 전문가 확인 후 정하시길 권합니다.

### 3.1 환불 방법

- 카드 결제: 결제 대행사(PG)를 통해 결제를 취소합니다. 카드사에 실제로
  반영되는 날짜는 카드사 일정에 따릅니다.

- 무통장입금: 고객에게 환불받을 계좌를 확인한 뒤 3영업일 이내에
  송금합니다.

## 4. 환불 기준: 타로카드(실물 상품)

| **상황**                                                    | **처리**                       | **기한·배송비**                                                                           |
| ----------------------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------- |
| 단순 변심                                                   | 반품 후 전액 환불              | 상품을 받은 날부터 7일 이내 신청. 반품 배송비 **\[금액\]**원은 고객 부담(제18조 제9항)    |
| 불량, 파손, 오배송, 설명과 다른 상품                        | 교환 또는 전액 환불(고객 선택) | 받은 날부터 3개월 이내, 그 사실을 안 날부터 30일 이내(제17조 제3항). 배송비는 판매자 부담 |
| 고객이 사용해 가치가 크게 줄어든 경우(카드 훼손, 사용 흔적) | 반품 불가                      | 제17조 제2항. 상품 화면과 포장에 미리 표시해야 적용할 수 있습니다.                        |

- 반품 상품을 받은 날부터 3영업일 이내에 환불합니다.

- 반품 보낼 주소: **\[결정 필요\]** / 택배사: **\[결정 필요\]

## 5. 강의

홈페이지 강의는 무료로 열람하므로 환불 대상이 없습니다. 유료로 바꾸게
되면 수강 기간과 진도에 따른 환불 기준을 그때 따로 정합니다.

## 6. 홈페이지에 표시할 안내 문구(초안)

확정되면 아래 문구를 홈페이지 해당 화면에 넣습니다. 결제 전에 고객이 볼
수 있어야 3장의 "상담 시작 후 환불 제한"을 적용할 수 있습니다.

| **위치**                 | **문구**                                                                                                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 예약 화면(결제 버튼 위)  | 상담 시작 전에는 언제든 전액 환불됩니다. 상담이 시작된 뒤에는 환불되지 않습니다. 다만 상담사 사정으로 상담이 제대로 이루어지지 않은 경우에는 전액 환불 또는 재예약해 드립니다. |
| 예약 화면(부재 안내)     | 예약 시간에 상담사가 매장 번호로 전화드립니다. 받지 못하시면 1회 무료로 다시 예약해 드립니다.                                                                                  |
| 예약 완료 화면·예약 조회 | 취소는 상담 시작 전까지 매장 대표전화(**\[번호\]**) 또는 1:1 문의로 신청해 주세요.                                                                                             |
| 타로카드 상품 화면       | 받은 날부터 7일 이내 반품할 수 있습니다(단순 변심 시 반품 배송비 고객 부담). 카드를 사용해 훼손된 경우에는 반품할 수 없습니다.                                                 |
| 상담 안내(공통)          | 사주·타로 상담은 참고용 해석이며 결과를 보장하지 않습니다. 의료·법률·투자에 관한 결정은 해당 전문가와 상의해 주세요.                                                           |
