## 8. 2차 화면 (2026-11-20 추가)

공통: 1차와 같은 토큰·부품을 쓴다. 입력칸은 높이 52px, 8px 모서리, 1px line, 16px 글자(휴대폰 확대 방지), 라벨 14px 700. 큰 버튼은 52px pill. 하단 탭 라벨은 지금 사이트와 같다(전화하기·로그인).

### 로그인 /login (screens/login.png)
뒤로 헤더 → 가운데 천사 로고(92px) + "다시 오셨네요" + 안내 2줄 → 이메일(메일 아이콘)·비밀번호(자물쇠 아이콘, 오른쪽 "표시") → 로그인 버튼 → "비밀번호 재설정 | 회원가입" → brand-tint 박스 "회원이 아니어도 괜찮아요"(비회원 예약 / 예약 조회 2열 버튼). 로그인 기능·오류 문구 동작은 그대로.

### 회원가입 /signup (screens/signup.png)
뒤로 헤더 → 제목·안내 → 이름·이메일(도움말 "인증 메일을 받을 주소예요.")·비밀번호·비밀번호 확인 → 약관 동의 카드(전체 동의 / (필수) 이용약관 보기 / (필수) 개인정보 수집·이용 보기) → "가입하고 인증 메일 받기" → "이미 회원이신가요? 로그인".
약관 동의는 지금 코드에 없으면 새로 추가하는 기능이다. 화면 작업과 분리해서 작업자에게 먼저 묻는다(약관 문서·동의 기록 저장 방식 결정 필요).

### 비밀번호 재설정 /forgot-password (screens/forgot.png)
뒤로 헤더 → 메일 아이콘 원(72px brand-tint) + 제목·안내 → 이메일 → "재설정 메일 보내기" → 스팸함 안내 카드 → "로그인으로 돌아가기".

### 예약 조회 /booking/lookup (screens/lookup.png)
헤더·상단 탭 → 제목·설명 → 흰 카드 안 폼(예약번호 + 도움말, 이메일, 조회 버튼) → "예약 상태 안내" 카드(입금 대기 halo / 예약 확정 brand / 상담 완료 brand-tint / 취소 line 배지 + 한 줄 설명) → brand-tint "예약번호를 잊으셨나요?"(로그인 / 매장 전화). 조회 결과 화면의 상태 배지도 같은 색 규칙을 쓴다.

### 클래스 /class (screens/class.png)
헤더·상단 탭(클래스 선택) → 제목 "클래스" + 설명 → 필터 pill(전체·사주·타로) → "과정 N개" → 과정 카드: 포스터 이미지(높이 210px, 위쪽 기준 자름) → 분야 칩(brand 바탕 흰 글자) + 강사 → 과정명 19px 800 → 기간·구성 아이콘 줄 → 키워드 칩 → 구분선 → "수강료 문의"(pink, 금액이 있으면 금액) + "자세히 보기".

### 클래스 상세 /class/[id] (screens/class-detail.png)
뒤로 헤더 → 포스터 전체(폭 100%, 높이 자동, 잘라내지 않음, alt에 포스터 핵심 문구) → 칩·제목·한 줄 소개 → 정보 표(강사·기간·수업·수강료) → 커리큘럼 번호 타임라인 → "이런 걸 배워요" 체크 목록 → "강의 영상" 카드(포스터를 어둡게 깐 썸네일 + 재생 버튼, 외부 링크 새 창) → 하단 고정 바(영상 보조 버튼 + "수강 문의하기" 주 버튼, 전화 연결). 하단 탭 없음.
고객 요청: 받은 포스터 2장(images/poster-saju.jpg, poster-tarot.jpg)을 각 과정의 대표 이미지로 쓴다. 클래스 DB에 이미지 칸이 없으면 DB 변경이 필요하다(마이그레이션 브랜치 먼저, Storage public-images/classes/). 포스터 안의 글자는 그림이라 읽히지 않으므로 기간·수업·커리큘럼은 텍스트로도 보여 준다.
포스터에서 읽은 내용: 사주교육 = 청남샘·가연샘, 1년 과정, 주 2회 2시간, 기초→중급→고급→실전상담. 타로카드 교육 = 2개월 집중(피드백 3개월), 유니버셜 웨이트 타로(가연샘, 주 2회 2시간) / 사주오라클카드(청남샘, 주 1회 2시간) / 만신타로·19금타로 전문과정 중 선택.

### 콘텐츠 /contents (screens/contents.png)
헤더·상단 탭 → 제목·설명 → 채널 바로가기 3칸(유튜브·인스타그램·블로그, brand 원 아이콘) → 필터 pill → "총 N건" → 콘텐츠 카드(썸네일 112×84, 채널 배지, 제목, 날짜 · 새 창으로 열기) → 빈 상태(로고 + "아직 올라온 소식이 없어요. 위 채널에서 먼저 만나 보세요."). 채널 주소는 고객 확정 전이면 바로가기 칸을 숨긴다.

### 타로샵 상품 /shop/[id] (screens/shop-item.png)

천사부적(매장 액자 사진 images/charm.jpg 기준): 5,000원, 종류 사랑·인연(The Lovers) / 소원성취(The Sun) / 재물(Ace of Pentacles). 그 밖의 상품·가격·배송비는 고객 확정 전이라 자리표시다. 타로샵 DB·주문 기능이 아직 없으면 이번에는 화면만 만들고 기능 범위는 작업자에게 먼저 묻는다.

### AI 사주 (screens/ai-saju.png, ai-saju-result.png)
- AI 풀이 기능은 다른 개발자가 만든다. 우리는 탭, 입력 화면, 결과 화면의 틀만 만든다. 결과 화면의 사주 기둥·오행·풀이 문장은 예시다.
- 입력 화면: 헤더·탭(AI 사주 선택) → brand 소개 배너 → 볼 수 있는 항목 4칸(타고난 성향·올해 운세·연애·인연·재물·직업) → 입력 카드(이름 선택, 성별 2칸 토글, 양력/음력 토글 + 연·월·일, 음력 윤달 체크, 태어난 시간 선택 + 시간 모름 체크, 개인정보 동의 필수 체크, "AI 사주 보기" 버튼, 이용 요금 안내) → 참고용 안내.
- 결과 화면: 뒤로 헤더 → 요약(이름·생년월일·시간·성별, 4기둥 한자 칸 brand/brand-tint) → 오행 분포 막대 → 풀이 카드 4개 → 전화상담 유도 카드(두 선생님 사진) → 참고용 문구 → 하단 고정 바(다른 사람 보기 / 선생님께 상담).
- 연결 방식은 그 개발자와 협의 후 정한다: ① API로 결과를 받아 우리 화면에 표시(디자인 통일, 권장) ② 그쪽 페이지로 링크 이동(가장 쉬움) ③ iframe 삽입. 정해지기 전에는 입력 화면까지만 만들고 버튼은 "준비 중"으로 둔다.
- 생년월일·태어난 시간은 개인정보다. 외부 서비스로 보내면 개인정보처리방침에 위탁·제공 내용을 적어야 한다.
