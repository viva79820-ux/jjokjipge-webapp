# 디자인 v2 구현 메모

이 문서는 `docs/design/v2/`에 보관한 시안 원본과, 웹앱에 실제로 적용하는 범위를 구분한다.
시안 HTML은 값의 출처이고, Next.js 화면을 통째로 대체하지 않는다.

## 이번 구현 범위

전체 전환은 네 묶음이다.

1. 기반: 자료 보관, 토큰, 화면 폭, 공통 부품, 지침
2. 전화상담 목록·상세와 상담사 공통 표시
3. 홈
4. 매장상담

이번 브랜치 `feat/design-v2-foundation`은 1번만 구현한다.
홈, 전화상담 목록·상세, 매장 화면의 새 구성은 아직 만들지 않았다.
공통 헤더·탭·색·글자·버튼·사진 자리·폭만 새 기준에 맞춘다.

## 상담사 데이터

- `fields`와 `careers`는 이미 DB와 관리자·고객 화면에 있다.
- 시안 인계 자료의 "복수 분야와 경력이 DB에 없다"는 설명은 오래된 내용이다. 그 설명 때문에 분야·경력을 다시 만들거나 샘플 값으로 덮어쓰지 않는다.
- 가연샘 경력은 시안에 나뉘어 있어도, 이미 승인된 내용과 DB에 저장된 원문을 우선한다.
- 번호, 작명 분야, 휴무, 전화상담 전용 표시는 DB에 없다. 없는 값을 화면이나 시드 데이터로 만들지 않는다.
- 시안의 인물 이름, 번호, 경력, 가격은 샘플이다. 운영 중인 상담사·상품·매장 정보로 쓰지 않는다.
- 관리자가 등록한 사진과 정보를 시안 샘플로 덮어쓰지 않는다.
- 상담사 사진은 기존 관리자 업로드와 Storage `public-images/counselors/` 흐름을 유지한다.
- `images/gayeon.jpg`는 저장소에 넣지 않는다.

## 가격

- 매장 방문 상담의 참고 가격은 `lib/store-price-config.ts` 한 곳에만 둔다.
- 상태는 고객 확정 전 참고 자료이고, 출처는 제공된 1호점 가격판 판독 값이다.
- 일반·중고등·인원별 금액은 나누어 둔다. 하나의 금액으로 합치지 않는다.
- 상담 시간이나 예약 가능한 상품 ID는 만들지 않는다.
- 전화상담·예약·결제 금액은 기존 `consult_products`를 그대로 쓴다. 매장 참고 가격으로 바꾸지 않는다.
- 이번 작업에서는 가격표를 화면에 추가하지 않는다.

## 확정한 후속 화면

아래에 적힌 동작은 결정만 기록한다. 이번 기반 작업에서는 구현하지 않는다.

- 홈·매장에 참고 가격을 보여줄 때는 위 설정 파일을 쓰고, 고객 확인 전 참고 가격임을 표시한다.
- DB에 작명 분야를 넣기 전에는 홈의 작명을 매장 화면의 작명 가격 안내로 연결한다.
- 전화상담 분야 필터는 전체·타로·사주를 유지한다. 시안 그림의 작명 필터를 지금 필터에 넣지 않는다.
- 상담사 상세는 메뉴를 고른 뒤 하단 예약 버튼으로 이동하게 바꿀 예정이다.
- 그때도 고른 기존 DB 상품 ID를 기존 예약 URL에 넘긴다. 예약·결제 서버는 유지한다.
- 상세 전용 헤더와 하단 예약 바, 번호 배지, 홈 배너·상담사 카드의 전체 재배치는 다음 묶음에서 한다.

## 보관 자료

- `DESIGN-SPEC.md`, `tokens.json`, `screens/`의 네 화면, `html/*.html`은 받은 원본 그대로다.
- 로고와 매장 사진은 `public/images/brand/`에 있다. DB `image_path`에 자동 등록하지 않는다.
- 기존 `docs/design/mood-*.png`는 이전 시안 기록으로 남겨 둔다. 화면 기준은 v2 명세다.
