# 쪽집게천사 운명나라 화면 디자인 명세 v2 (2026-11-13 확정)

이 폴더는 휴대폰 화면 시안(Claude Design)을 코드로 옮기기 위한 자료다.
- `screens/*.png`: 확정 시안 화면 캡처(390px 폭, 2배율). 이 그림과 똑같이 보이게 만드는 것이 목표다.
- `html/*.html`: 시안의 실제 HTML·CSS. 크기, 색, 간격, 모서리 값은 여기서 정확히 읽는다. 시안 전용 마크업이라 그대로 복사하지 말고 기존 컴포넌트 구조에 맞춰 옮긴다.
- `images/`: 로고와 매장 사진(웹용으로 줄인 것).
- `tokens.json`: 디자인 토큰(색, 글자, 간격, 모서리).

## 1. 방향

- C안·B안 분위기 시안은 폐기한다. 홍카페 같은 실제 운세 서비스 수준을 목표로, 쪽집게천사 고유 요소를 넣는다.
- 색과 로고는 고객의 천사 로고에서 가져왔다. 어두운 가지색(기존 brand), 한지 미색 바탕, 금색 테두리, CSS 장식선은 모두 없앤다.
- 쪽집게천사 고유 요소:
  - 번호 배지: 매장 간판처럼 상담사 번호를 분홍 원에 "1번"으로 표시한다.
  - 실제 매장 강조: "동성로 1·2호점, 실제 매장 선생님" 띠와 매장 사진.
  - 천사 로고: 헤더 왼쪽, 사진이 없는 상담사의 사진 자리, 푸터.

- 배너: 16px 여백 안, 높이 228px, 16px 모서리, brand 바탕. 왼쪽 글자(배지, 이름 28px 800 흰색, 경력 2줄 14px, 흰 바탕 brand 글자 "상담 예약하기" 버튼), 오른쪽 상담사 사진(폭 160px, 위쪽 기준으로 자름). 오른쪽 아래 "1 / 3" 페이지 표시. 슬라이드는 기존 drag-row(embla) 방식 유지. 데이터: 추천 상담사(is_recommended) 중 사진이 있는 상담사.

## 5. 데이터와 범위

- 기능(예약, 결제, 회원, 관리자)은 바꾸지 않는다. 화면 모양만 바꾼다.
- 매장 가격표는 DB가 아니라 설정 파일 하나에 둔다(AGENTS.md 9장 "고객 확정 전 값은 설정값 한 곳에" 규칙). 값은 결정사항의 1호점 가격판 판독값이고 "매장 가격 기준"으로 표시한다.
- 시안에 있지만 지금 DB에 없는 것(번호, 경력, 여러 분야, 작명 분야, 휴무)은 DB 변경이 필요하다. 이건 화면 작업과 분리해 마이그레이션 브랜치로 먼저 한다(AGENTS.md 규칙). DB 변경 전에는 값이 없으면 그 요소를 숨기도록 만든다(번호 배지 없음 = 배지 숨김).
- 상담사 사진(가연 선생님 `images/gayeon.jpg`)은 코드에 넣지 않는다. 상담사 관리 화면이 생기면 Storage `public-images/counselors/`에 올린다.
- 로고와 매장 사진은 `public/images/brand/`에 둔다(공개해도 되는 사진만 골라 둠. 손님 얼굴이 보이는 사진은 넣지 않았다).
- 주소, 전화번호, 사업자 정보, 영업 시작 시간은 고객 확정 전이므로 [ ] 자리표시로 둔다.

## 6. 지금 코드의 토큰과 맞추기

`app/globals.css`의 `@theme` 색을 2장의 값으로 바꾼다. 이름을 최소로 바꾸려면 예: brand → #7C429A, brand-deep → brand-strong 역할 #5E2F78, brand-soft → #F3EAF8, background → #F7F3FA, surface → #FFFFFF, foreground → #2A1F33, muted → #6B6175, border → #E7E1EC. gold 계열은 쓰지 않으므로 halo(#FFE780), pink(#C2255C)를 새로 만들고, gold를 쓰던 곳을 모두 찾아 바꾼다. radius-card 16px, 버튼은 pill.
